# Yoldash SEO status — 2026-10-12

## Verified
- Static checker: 71 HTML pages, 69 structured-data blocks, 69 sitemap URLs.
- Live baseline: all 69 sitemap URLs returned HTTP 200 with a matching self-canonical.
- robots.txt and both static and live-load sitemaps returned HTTP 200.
- Unknown URL returned a real HTTP 404.
- Localized canonical/hreflang reciprocity, metadata consistency and internal links passed the automated checker.
- Nine Persian, Turkish and English pages gained distinct practical content and relevant internal links.
- Public load pages use real crawlable detail links and sharing metadata. ItemPage describes a road-freight Service; it does not claim the cargo post is an in-stock product Offer.
- Invalid, expired and failed load requests cannot return an indexable success page. Transient network errors return 503, not a false missing-listing state.
- Live-load sitemap emits stored valid modification timestamps only, not the request time.
